Projects

Shelfr

Shelfr is a simple Media Collection Manager I built with C++ and the Qt Framework for a University course project, it allows you to manage your personal media collection including books, films, music and videogames (with some tweaks its possible to extend the items you can add). Everything is stored for persistency in a simply formatted json file. This project was made for the BSc Computer Science course "Object Oriented Programming".

Matrix Diagonalization

Matrix Diagonaliation is a proejct made in MATLAB whose goal is to study the numerical diagonalization of matrices generated with prescribed eigenvalues and multiplicities, with this project we calculate the maximum multiplicity of eigenvalues for which the process remains stable and the effect of clustering eigenvalues on the success diagonalization of the matrix, all of it is nicely demonstrated with graphs.

Sentiment-News Analysis Pipeline

SNAP is my BSc Thesis Project, it's a Machine Learning Model that combines various features like the energy cost of production for a Bitcoin, the hashrate, the market price and the estimated sentiment value towards it, calculated by a Google Gemini model and taken from reddit posts and then gives it to an XGBoost Classificator to predict wether the next week the coin will gain or lose value.
